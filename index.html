Features

Everything you need — built in

aiClaw is not just a chatbot. It's a full AI agent with memory, tools and integrations.

Long-term memory

Two-level memory: SQLite for dialog history and pgvector for semantic fact search. The agent remembers everything important.

Hot LLM switching

Switch model mid-chat without restart. Claude, GPT-4o, Gemini, GigaChat and local models.

Task scheduler

Built-in cron scheduler. Reminders, recurring reports, automated digests — all configured by voice.

Knowledge base (Vault)

Structured wiki of your projects. The agent auto-logs decisions and updates the base. Always in context.

Integrations

Cloudflare, SWeb, Hestia, n8n, Perplexity, Playwright. Manage infrastructure directly from Telegram.

Image generation

Flux Dev, Kontext, Schnell, Ultra via fal.ai. Create visuals with one command right in the messenger.

Privacy & security

The agent runs only on your server. No external storage, no SaaS. Your data stays with you.

Extensibility

BotModule plugin architecture. Any custom commands and integrations added without touching the core.

Group chats

Full support for Telegram groups and topics. Flexible session isolation: shared, per-user, per-topic.

For teams

One agent.
The whole team.

aiClaw works in corporate Telegram and Max chats. Choose the mode for your scenario — from a shared duty assistant to a personal assistant for every employee.

Групповые чаты
Топики Telegram
Режим per-user
Изоляция сессий

The mode is set in config and can be changed without restart. Different rules can be set for different groups — e.g. passive mode in a work chat, personal in DMs with the manager.

shared

Shared chat

One dialog for the whole group

  • All participants' messages go into one shared session
  • The agent sees the full chat context and knows who wrote what
  • Good for duty assistant, digests, briefings
  • Shared memory — facts from conversations available to all
Иван: какой статус по задаче №42?
Мария: и кто ответственный?
🤖 Задача №42 в работе у Петра,
дедлайн — 3 июня.
per_user

Personal

Separate dialog for each

  • Each group member gets their own isolated session
  • The agent remembers each employee's history and context separately
  • Privacy: others' messages don't get into your context
  • Ideal for teams where everyone has their own tasks and projects
Иван: покажи мои задачи
🤖 Иван, у вас 3 задачи:
1. Отчёт · 2. Встреча · 3. КП
— Мария видит только свои —
mention_only

Passive

Responds only when addressed

  • Stays silent in the background — doesn't react to regular messages
  • Activates on @mention or a keyword
  • Doesn't interrupt team conversation, but always at hand
  • Optimal for active work chats
